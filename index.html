        Check the file before opening

        These tools are free. Pick your operating system, download, and run. Small apps are often flagged by Windows or macOS as coming from an unknown publisher. That is expected, but compare the file's SHA-256 checksum with the one shown on this page before you open it.

        Windowscertutil -hashfile FILE_NAME SHA256
macOSshasum -a 256 FILE_NAME
Linuxsha256sum FILE_NAME
